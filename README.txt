КАЛОРИИ — установка
1. Создайте публичный репозиторий на github.com (например calories).
2. Загрузите все файлы архива в корень репозитория (Add file → Upload files → Commit changes).
3. Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.
4. Когда GitHub покажет адрес сайта, откройте его в Safari на iPhone, нажмите «Поделиться» → «На экран Домой» → «Добавить».
5. После первого успешного открытия с интернетом приложение сможет открываться офлайн. Записи хранятся локально; периодически экспортируйте копию через Настройки.
Ввод: «Блины 270» в одно поле или название и калории отдельно. БЖУ необязательны. Приложение поставляется без вымышленных записей.
